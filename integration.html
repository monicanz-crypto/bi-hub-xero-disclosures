Monica Ferguson private Xero integration

This private integration is used only by Monica Ferguson to connect her own Xero organisation to her private Business Intelligence Hub. It is not offered to customers or the public.

The initial connection requests openid, profile, email, and accounting.settings.read. The accounting.settings.read scope is a permission that could authorize organisation and settings endpoints, but the initial flow calls no Accounting API endpoint. It calls Xero identity and token services, GET /connections, and a request to DELETE /connections/{connectionId} for the exact returned connection.

No Accounting API endpoint is called during this initial flow. In particular, the integration does not call GET /Organisation, GET /Payments, or GET /Journals, and it does not read invoices, payments, journals, bank transactions, contacts, reports, or other accounting records.

After validating the connection inventory, the integration requests deletion of the exact connection. A successful DELETE /connections/{connectionId} returns HTTP 204, which documents that Xero has deleted the connection. The integration makes no separate post-deletion GET /connections readback. If the deletion request is not accepted, the flow fails and deletion remains unconfirmed, so the connection may remain. Connection deletion is not access-token revocation; the unpersisted access token may remain valid until expiry, which is up to 30 minutes.

Security events use a fixed data-free taxonomy and are appended directly to the private Business Intelligence Hub database using server-assigned time and sequence. The dedicated logger credential cannot read or directly change the event or chain tables. A logging failure blocks the connection flow.

Any future accounting-data access requires separately authorized scopes and updated information where necessary.
